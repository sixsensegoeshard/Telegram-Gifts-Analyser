# Проверка Gift Signal — 10 октября 2026

Текущая версия: реальная Telegram Mini App запущена на компьютере владельца через временный HTTPS-туннель. **45 из 45 автоматических тестов прошли**, синтаксис 27 JavaScript-файлов проверен. Среда: macOS, Node.js 24.13.0. Внешних npm-зависимостей нет. SQLite в этом Node выводит предупреждение об экспериментальном статусе.

## Что проверено на реальном подключении

- Bot API подтвердил @tradingnftgift_bot; у него нет активного webhook. Работает один экземпляр polling.
- Описание до нажатия «Начать» сохранено для языка по умолчанию и ru. Приветствие создано и закреплено в личном чате подтверждённого владельца. `getChat` подтвердил pinned_message; кнопки приветствия и меню ведут на актуальный адрес приложения. Telegram нормализует корневые URL добавлением `/`.
- Публичный HTTPS `/health` — 200. `/api/status` — live, online, Portals connected, 122 свежих коллекции. MRKT — not-connected, Gift Charts — requires-access. Публичный доступ к портфелю отсутствует: вход без initData — 401. `/.env` — 404.
- Portals отдаёт коллекции двумя страницами (100 + 22). Цена Toy Bear во время проверки — около 32,8 TON; значения динамические. Проверены реальные NFT Toy Bear с UUID, Telegram-номером, ценой, моделью, фоном, узором и ссылкой в Portals.
- Gift Charts `/api/v1/gifts` без авторизации вернул 401. Подтверждённый публичный API MRKT не найден; источник не помечен подключённым. Не применялся обход авторизации или Cloudflare.
- Во время перезапуска Cloudflare один раз не создал туннель. Обнаружен и исправлен ошибочный разбор `api.trycloudflare.com` как адреса Mini App. Новый туннель успешно запущен и проверен извне.

Время «получено» — время наблюдения нашего сервера, а не подтверждение времени обновления исходного источника. Коллекции опрашиваются каждые 120 секунд; предложения кэшируются на минуту. История флора собирается с момента подключения; изменение за 24ч появится после накопления суток. Графики не дорисовываются.

## Автоматические сценарии

| Область | Подтверждено |
| --- | --- |
| Telegram-вход | Корректная HMAC, signature, возраст initData; отклонение подделки, другого токена, дубликатов и неверного ID |
| HTTP и изоляция | CRUD портфеля и алертов, разные пользователи, отказ в изменении чужой записи, истечение сессии |
| Листинги | Требуется авторизация; нельзя передать произвольный URL вместо ID коллекции |
| Проверка ввода | Числа, даты, будущая дата, невозможное 30 февраля, размер и Content-Type, origin, запрет проксирования браузерного демо |
| Расчёты | Цена за единицу × количество, P/L/ROI, неполная оценка, комиссии покупки/продажи/переноса |
| Качество данных | Пропущенные метрики — null; устаревшие/будущие цены отключают score; число продаж — по данным источника |
| Portals | Пагинация, дубликаты, числовые строки, время наблюдения, CDN whitelist, фильтрация только listed и нужной коллекции, отсутствие вымышленного флора модели |
| Кэш и лимиты | Общий кэш предложений, объединение одновременных запросов, Retry-After после 429, отсутствие немедленных повторов, сохранение последнего реального снимка после ошибки |
| Другие адаптеры | GiftAsset по документированной схеме и нормализованный JSON feed; отсутствующие метрики не превращаются в нули |
| SQLite | Покупки и избранное переживают перезапуск; удалённое демо не восстанавливается автоматически |
| Приветствие | Одно сообщение без копий после /start, обновление URL, восстановление удалённого сообщения, закрепление, ограничения длины описаний |
| Туннель | Адрес служебного API Cloudflare не может попасть в кнопку приложения |
| Алерты | Только разрешённые пользователи, свежий флор, верный получатель, одна успешная доставка, повтор после сетевой ошибки |
| Ассистент | Явное демо и локальный fallback, отсутствие обещаний исполнимого арбитража |
| Статика | CSP, SVG/HTML/JS, отсутствие доступа к .env и исходникам backend |

Команды: `npm run check`, `npm test`. Тесты используют временные базы и имитированный Bot API; денег, автопокупок и рассылок не выполняют. GitHub Actions workflow подготовлен, но CI на удалённом репозитории не запускался.

## Проверка интерфейса

Финальный интерфейс проверен в браузере на отдельном localhost стенде с настоящими котировками Portals и отдельной временной базой. Пользовательский портфель этим стендом не изменялся. Данные рынка реальные; примерный портфель стенда служит только проверке отображения.

- Поиск Toy Bear, переход в коллекцию, открытие 20 предложений, загрузка фото и моделей.
- Бюджет 33 TON фильтрует список; в момент проверки осталось пять предложений. Это фильтр загруженных 20 NFT, а не поиск всего маркета.
- Ссылка каждого предложения содержит UUID конкретного NFT Portals. Покупка не выполнялась.
- `total_count=0` при непустом списке не показывается как ноль доступных NFT.
- Портфель, форма покупки и окно источников отображаются без горизонтального переполнения.
- Ширины 320, 390, 768 и 1440 px: `scrollWidth` страницы совпадает с шириной viewport. На 320 px окно предложения и форма не переполняются.
- В журнале браузера нет ошибок JavaScript на проверенных переходах. Изображения загружаются с разрешённых CDN; отсутствие фото заменяется нейтральным значком.

Снимки: `artifacts/portals-market-mobile.png`, `artifacts/portals-offers-mobile.png`. Артефакты исключены из Git.

Ранее на отдельном демо были проверены редактирование/удаление покупок, избранное, CSV, сортировки, сценарий комиссий и ответы ассистента. Эти сценарии дополнительно покрыты автоматическими тестами.

## Эксплуатация и оставшиеся проверки

Перед обновлением сделана резервная копия через SQLite backup API; база пользователя сохранена. Один основной процесс запускает сервер, бот, туннель и предотвращение автоматического сна. Компьютер и интернет должны оставаться включёнными. Адрес туннеля временный и меняется при перезапуске; pinned welcome и меню обновляются автоматически. Main Mini App в BotFather, если настроена вручную, требует обновления URL отдельно.

Владелец ранее подтвердил открытие Mini App в Telegram. Новую версию нужно открыть повторно из обновлённой кнопки. Дополнительно остаются: проверка на разных клиентах Telegram, реальные ценовые алерты по намеренно заданному пользователем условию, обработка блокировки бота, качество/полнота и задержки поставщика на длительном сборе, нагрузка, резервное восстановление и мониторинг. Docker/Caddy на VPS и внешний AI не запускались.

Для оценки выгодных моделей нужны сопоставимые флоры атрибутов, история реальных продаж, комиссии и второй маркет. Дешёвое предложение и score не являются подтверждением прибыльности. В этой версии нет автопокупок, кошелька, автоматического импорта инвентаря или проверенного торгового прогноза.
